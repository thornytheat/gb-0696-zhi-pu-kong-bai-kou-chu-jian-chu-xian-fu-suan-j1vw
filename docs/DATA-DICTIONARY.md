# 质谱字段与规则

sample_id保留前导零。kind取standard、blank、sample、control。area与internal_area为峰面积。level为标样浓度，单位支持ug/L、mg/L、ng/L；统一为ug/L。dilution必须大于0。

site为可选第10列（站点编号）。仅sample类样品参与站点聚合；site为空、N/A、NULL、未知、"-"等哨兵值视为站点不明：单样品结果照常复算并保留，但不混入任何站点代表值，在复核页与导出中单列。旧版无site列CSV继续兼容，其样品全部按站点不明处理。

每批每检测项至少3个独立浓度点。最小二乘使用Decimal，分母为零拒绝；斜率非正拒绝。空白取同批同项的浓度中位数。净浓度允许为负；不能提前截零。稀释后检出限=0.05×倍数。控制样相对误差超过20%阻断。超过标曲响应范围优先于其他质控判断。

站点季度代表值（M7，规则码ND_LOD_HALF，规则版本随RULE_VERSION）：按(站点,检测项)分组求算术均值。定量实测值(PASS)直接参与；未检出(BELOW_LOD)与空白扣除后负值(NEGATIVE_BLANK)不按零处理、负值不直接平均，统一按各样品稀释校正后LOD的1/2代换后参与；OVER_RANGE、CONTROL_FAIL样品排除。原始样品浓度、限定符与来源行号原样保留可追溯。含代换或排除样品的站点，其代表值仅供季度间趋势比较，不可直接用于合规判断；全部实测的站点代表值可用于比较，合规判定仍以单样品合格结果为法定依据。聚合生成失败时批次阻断、拒绝写入并保留同摘要旧版结论。Decimal确定性计算，同输入重跑结果一致。

重复编号相同内容标DUPLICATE，不同内容标KEY_CONFLICT。采信包括标曲和空白，最终样品数不等于输入采信数。行数对账独立于样品结果数。

同一批次同一分析项内sample_id唯一；相同样品编号可在不同分析项或批次中复用。
